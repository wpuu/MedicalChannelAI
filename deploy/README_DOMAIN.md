# Pilot 域名建议

天津 Pilot 给渠道客户演示时，访问入口可以先使用免费子域名，例如：

- `mcai.dpdns.org`
- `medicalai.dpdns.org`
- `medai.dpdns.org`

优先推荐短、容易口头转述的名字。实际是否可注册以域名服务当时可用性为准。

## 为什么 Pilot 可以先用 dpdns.org

- 不需要先决定正式品牌名；
- 可快速绑定到单台 VPS；
- 后续换正式独立域名时，数据库、API、客户画像、跟进、提醒和模型结果都无需迁移，只修改入口域名/证书/反代配置；
- 适合天津少量客户验证工作流。

## 为什么正式收费版不长期依赖免费子域名

正式商业化后建议购买独立域名，主要为了品牌控制、长期稳定性、企业信任和避免受免费域名上级策略变化影响。

## 备选免费入口

- `*.duckdns.org`：稳定的免费 DDNS，但更像技术/家庭服务器地址；
- `*.dedyn.io`：deSEC 提供的免费 DynDNS，技术属性同样较强。

因此在“给老杨演示、暂不决定正式品牌域名”的场景下，当前默认仍选 `*.dpdns.org`。
