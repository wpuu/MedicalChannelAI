# Pilot 域名建议

天津 Pilot 给渠道客户演示时，优先使用简短、能看出业务含义、看起来不像家庭 DDNS 的免费子域名。

DigitalPlat 当前官方列出的可用后缀包含：`.qzz.io`、`.dpdns.org`、`.us.kg`、`.xx.kg`、`.qd.je`。本项目只优先考虑前两种；其他后缀不作为默认。

## 当前推荐顺序

1. `medradar.qzz.io` — 第一选择；短、业务含义明确，最适合给老杨看；
2. `medicalai.qzz.io` — 含义直观，但品牌感弱于 medradar；
3. `medradar.dpdns.org` — 稳妥备用；
4. `mcai.dpdns.org` — 最短的内部/备用入口。

实际是否可注册以申请时可用性为准。

对 `.dpdns.org` 避免使用连字符 `-`；已有用户反馈带连字符的名称会出现不可用情况。

## 为什么 qzz.io 更适合商务演示

`medradar.qzz.io` 比 `medradar.dpdns.org` 更短，也更接近普通 SaaS/AI 产品网址的视觉感受。对非技术客户而言，`dpdns` 更容易被理解成动态 DNS 或技术测试地址。

这只是演示入口选择，不代表把免费域名当成正式品牌资产。

## 为什么 Pilot 可以先用 DigitalPlat 免费域名

- 不需要在产品定位尚未完全验证前购买并绑定正式品牌域名；
- 可以委派给外部 authoritative DNS；
- 可快速指向单台 VPS；
- 后续换正式独立域名时，数据库、API、客户画像、跟进、提醒和模型结果都无需迁移，只修改入口域名/证书/反代配置；
- 适合天津少量客户验证工作流。

## 正式收费版

正式商业化后建议购买独立域名，主要为了品牌控制、长期稳定性、企业信任以及降低上级免费 namespace 政策变化带来的依赖。

免费域名不建议承担企业邮箱主域名，也不建议作为长期合同、宣传物料中的永久品牌地址。

## 其他免费备选

- `*.duckdns.org`：免费 DDNS 成熟，但明显偏家庭服务器/技术用途；
- `*.dedyn.io`：deSEC 免费 DynDNS，DNS 安全能力好，但同样偏技术用途。

因此当前默认：**`medradar.qzz.io` 第一选择，`medradar.dpdns.org` 第二选择。**
