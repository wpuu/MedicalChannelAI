# Pilot 域名建议

天津 Pilot 给渠道客户演示时，优先使用简短、能看出业务含义的免费子域名。

当前推荐顺序：

1. `medradar.dpdns.org` — 对应“医疗商机雷达”，最适合给业务客户演示；
2. `medicalai.dpdns.org` — 含义直观，但更通用；
3. `mcai.dpdns.org` — 最短，适合内部测试或备用入口。

实际是否可注册以申请时可用性为准。避免使用连字符 `-`，已有 dpdns.org 用户反馈带连字符的名称会出现不可用情况。

## 为什么 Pilot 可以先用 dpdns.org

- 不需要先决定正式品牌名；
- 可快速绑定到单台 VPS；
- 后续换正式独立域名时，数据库、API、客户画像、跟进、提醒和模型结果都无需迁移，只修改入口域名/证书/反代配置；
- 适合天津少量客户验证工作流。

## 为什么正式收费版不长期依赖免费子域名

正式商业化后建议购买独立域名，主要为了品牌控制、长期稳定性、企业信任和避免受免费域名上级策略变化影响。

## 备选免费入口

- `*.duckdns.org`：免费 DDNS 成熟，但视觉上更像技术/家庭服务器地址；
- `*.dedyn.io`：deSEC 的免费 DynDNS，安全与 DNS 能力好，但同样更偏技术用途。

因此在“先给老杨演示、暂不决定正式品牌域名”的阶段，默认仍选 `*.dpdns.org`；如果 `medradar` 可注册，优先用它。
