# 中国大陆访问验收

状态：`REQUIRED_BEFORE_BUSINESS_DEMO`

目标：老杨在天津使用普通国内网络，**不开 VPN，并能在微信内置浏览器直接打开**商务 Demo。

## 当前 Demo 地址

```text
https://medicalai.qd.je/
```

用户已实测：

- 中国大陆网络可打开；
- 微信内置浏览器可直接点击打开。

当前 `medradar.dpdns.org` 微信实测打不开，因此不作为商务 Demo 入口。

这个结果按真实目标环境优先，不因为 `dpdns.org` 在 DNS/PSL 层更标准而反向覆盖用户体验。

## 默认拓扑

```text
medicalai.qd.je
  ↓ public DNS
境外源站（优先香港 / 东京 / 新加坡）
  ↓ HTTPS
Caddy
  ↓
静态 H5
```

第一轮验收不把 Cloudflare 免费全球代理作为大陆可访问性的前提。`qd.je` 当前也存在 Cloudflare zone / PSL 兼容问题，因此 Demo 不依赖 Cloudflare。

## 服务器优先级

1. 香港
2. 东京 / 大阪
3. 新加坡
4. 美国西海岸
5. 现有美国 Google VPS 只作为零新增成本测试方案

服务器不在中国大陆时，不把 ICP 作为当前静态 Demo 前置条件；但实际访问质量必须用国内网络 + 微信实测。

## 前端硬要求

Demo 首屏不得依赖：

- Google Fonts；
- jsDelivr / unpkg / cdnjs；
- Google APIs；
- `*.vercel.app` / `*.pages.dev` / `*.workers.dev` 作为运行时依赖；
- 外部图片、字体、脚本作为首屏必需资源。

React、图标、CSS和字体策略全部随构建产物本地提供或使用系统字体。

`deploy/build-web.sh demo` 会：

- typecheck；
- build；
- 扫描外部 script/link/CSS 运行依赖；
- 检查 Demo dist 总大小预算。

## 发给老杨前的真实验收

### A. 微信内置浏览器

这是第一优先级。

在微信聊天中点击：

```text
https://medicalai.qd.je/
```

必须确认：

1. 不出现“已停止访问该网页”或安全拦截；
2. 首屏正常出现；
3. TOP1 详情可打开；
4. 返回首页正常；
5. Demo 沟通话术可生成；
6. “已联系”可操作；
7. “重置演示”正常；
8. 刷新不会 404/白屏。

### B. 国内手机流量

关闭 Wi-Fi、关闭 VPN，用中国移动 / 联通 / 电信任一手机网络，在系统浏览器重复：首页、TOP1、刷新、返回。

### C. 第二条国内网络

至少再用另一运营商或家庭宽带重复基本浏览路径。

### D. 无 VPN

全过程确认：

```text
VPN / Clash / WARP / 全局代理 = OFF
```

否则结果无效。

## 通过标准

发给老杨前至少满足：

- 微信内置浏览器可直接打开；
- 2 条独立国内网络均能访问；
- HTTPS 无证书警告；
- 375px 手机宽度无横向滚动；
- 首屏不依赖外部 CDN/字体；
- 刷新不会 404；
- Demo 明确显示“演示数据”；
- 虚构项目不跳转成真实采购公告；
- 依据不足项目不能生成话术。

任何一项失败，先修复，不发链接。

## 免费域名可能被微信后续拦截

微信安全策略和免费后缀信誉会变化，所以当前“可以打开”不是永久保证。

处理方式：

1. 每次重要演示当天先在微信重新点一次；
2. 若 `medicalai.qd.je` 被拦，换新的临时 Demo 域名；
3. 不迁代码、不迁数据，只改 DNS / Caddy 域名；
4. 正式 Pilot 使用独立长期可控域名，不把免费公共后缀当品牌资产。

## 如果美国 VPS 访问慢

处理顺序：

1. 换香港 / 日本 / 新加坡源站；
2. 保持 `medicalai.qd.je`；
3. DNS 切新 IP；
4. Caddy 配 HTTPS；
5. 重新做微信 + 两条国内网络验收。

不要先换前端框架，也不要为了跨境访问先叠更多 CDN。
