## 二、用户使用路径及判断

用户确认经营地区、血细胞分析仪整机具体产品／规格、真实授权与资质 → 查看今日／商机池 → 查看官方公告和原文证据 → 核对具体产品匹配、资格状态及报名时限 → 选择推进／观察／结束 → **明确保存**下一步和提醒 → 再登录仍可查。

每条商机依次判断：

1. **事实**：官方页面确实指向天津采购单位、公开具体设备及有效公告；不足则未知／不推荐，不补造医院、预算、日期或联系方式。
2. **整机匹配**：公告采购对象与客户确认经营的血细胞分析仪整机、规格逐项对照；三分类／五分类及技术参数以公告和客户资料为准。仅关键词相似或仅属于“检验科”不算匹配。
3. **资格三态**：**满足／不满足／未知**，须写明依据和待补材料；资料缺失保持未知，**未知不能说可投**；产品不能替客户作最终资质承诺。
4. **行动窗口**：以公告的明确日期与当前时点为准；已过报名截止不因未开标而恢复“现在能报名”；采购意向不得误写成正式招标。
5. **下一步**：展示可解释的建议、来源链接和待核事项；允许零推荐。公开商机关闭不清除既有客户私有跟进历史。

## 三、前后台“刷新”及故障表达

- **页面重新加载**：只读取后台已经发布的版本，不开始抓取，也不把新时间标签当新商机。私有跟进的刷新单独读跟进记录。
- **后台受控采集**：依已授权的来源和频率访问官网、核验、发布；失败保留可用旧已验证数据和来源失败标记，其他来源不因单源失败自动报成功。
- **建议展示**：数据发布时间、每来源最近完整成功采集时间、来源异常／过期提示。频率、国内性能和覆盖率需真实运行验收后再承诺；15分钟调度检查不等于每源15分钟更新。

## 四、六项业务通过标准（全部待真实验收）

| 编号 | 验收项 | 成功证据及通过条件 |
| --- | --- | --- |
| B1 | **真实商机更新** | 冻结来源、产品条件和起止时间，人工逐条对照官方索引／详情并统计漏报误报；**至少1条观察期真实新增的匹配公告**经发现→核验→发布→页面打开，官方字段与页面一致。若期间无新增，只验“零结果处理”，B1仍待验 |
| B2 | **页面重新加载** | 保存发布前后版本及页面内容，后台成功发布后页面能读取真实新版本，且浏览器操作不触发采集；只有时间标签变化不通过 |
| B3 | **可信匹配／资格／时间** | 用真实依据覆盖整机匹配、不相关、资格满足／不满足／未知、报名结束或意向未招标案例；解释清楚且无“未知即有资格”或过期可投 |
| B4 | **故障诚实** | 官方源失败、部分详情未核或覆盖逾期时明确提示；不伪造源最近成功时钟，旧有效数据及其他来源结果保留且不误标为新 |
| B5 | **私有跟进闭环** | 账号A明确存状态、下一步及提醒，刷新／退出重登录仍可读、可修改及确认；账号B无法读取A数据，提醒确认不自动改变商机阶段 |
| B6 | **更正、关闭与历史** | 真实官方更正／终止／截止后，列表、详情和建议一致变化，客户私有历史仍在；缺真实样本则线上项待验，离线回放不能冒充真机通过 |

**证据要求：** 每项留官方原文链接／时间、客户确认资料（私有隔离）、发布前后标识、用户可见结果、失败和退出条件；每项标记PASS／FAIL／NOT_VERIFIED。**不可用旧的16/15条分母、1213/10/3测试数、HTTP 200、快照时钟或模拟数据替代真实验收。**
