## 使用流程与判断规则

**填产品资料 → 看今日优先事项／商机池 → 核对详情和官方依据 → 选择推进／观察／结束 → 记录下一步和提醒 → 再次打开继续跟进。** 商机过期退出公开池，私有跟进记录仍保留。

每条依次判断：**官方事实 → 具体产品匹配 → 资格满足／不满足／未知 → 有效行动窗口 → 下一步动作。** 资格未知先核实；报名结束不能因尚未开标而恢复新进入机会；允许零推荐。卡片展示采购内容、匹配理由、资格待核项、有效时间、官方链接和动作，不只给总分。

## 如何刷新

- **重新加载商机：** 读取后台已发布结果，不启动采集。浏览器刷新属于此类；“我的跟进”刷新只重读跟进记录。统一“重新加载”文案是待实施建议。
- **后台采集新商机：** 由受控后台任务访问官网、核验后发布，普通用户不直接触发。失败保留旧已验证数据，并显示异常。
- 页面建议分别显示**来源最近完整成功采集时间、数据发布时间、覆盖异常**。具体频率和时效等真实运行后再承诺；15分钟调度检查不等于每源15分钟更新。

## 可用版验收（六项均待业务验证）

| 项目 | 通过标准 |
| --- | --- |
| 真实更新 | 固定来源／产品／起止时钟，人工核对官方清单并逐条记录漏报、误报；至少1条期间真实新公告经核验发布后可在页面打开，关键字段和依据一致。没有新公告只验完整空结果，不冒充新公告链路通过 |
| 重新加载 | 对照发布前后版本与内容，页面能读到已发布新版本且不触发采集；仅时间标签变化不通过 |
| 判断可信 | 直接匹配、不匹配、资格未知／不满足、报名已结束分别有案例；未知不说可投，不相关不包装成机会 |
| 故障诚实 | 来源失败、部分未核或超期时有提示，不刷新该源完整成功时间；旧已验证数据及其他来源独立更新保留 |
| 跟进闭环 | 登录后保存状态、下一步和提醒，重新加载及退出再登录仍在；可修改／完成提醒，不同账号看不到彼此记录 |
| 更正／关闭 | 官方更正、终止或窗口结束后，列表／详情／建议一致更新，跟进历史保留；样本回放和线上实测分开，缺真实样本记待验，不无限等待 |
