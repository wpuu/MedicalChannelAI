## 目标

让中国大陆用户访问：

`https://medicalai.qd.je`

时：

- 地址栏始终保持 qd.je；
- 浏览器不直接连接 `*.vercel.app`；
- `/today`、`/api/status`、AI POST 请求全部可用；
- 不使用常驻付费 VPS。

## 架构

```text
中国大陆浏览器
 -> medicalai.qd.je
 -> Tencent EdgeOne Pages
 -> Edge Function reverse proxy
 -> medicalchannelai.vercel.app
```

Vercel 保持权威应用源站；EdgeOne 只做中国访问入口和反向代理。

## 为什么选 EdgeOne Pages

- 长期免费套餐；
- 支持自定义域名，包括子域名；
- 支持 Edge Functions；
- Edge Functions 支持标准 Fetch/Request/Response API；
- 可直接从 GitHub 项目部署；
- 不需要常驻服务器；
- 中国/亚太访问是该产品重点场景。

## 已实现

目录：

`ops/edgeone-cn-proxy/`

包含：

- `edge-functions/index.js`：根路径代理；
- `edge-functions/[[default]].js`：多级路径代理；
- `proxy.js`：统一回源逻辑；
- `edgeone.json`；
- `package.json`；
- `public/index.html` fallback。

代理规则：

- `/` 内部回源到 `/today`，不返回浏览器重定向；
- 其他 path/query 原样回源；
- 动态请求 body 原样传递；
- 回源 URL 固定到 `https://medicalchannelai.vercel.app`；
- Vercel 返回的绝对 Location 若指回 Vercel，自动改写成 qd.je；
- CORS Allow-Origin 若精确指向 Vercel origin，自动改写成 qd.je origin。
