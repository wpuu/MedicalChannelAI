# MCAI-CN-ENTRY-005 · medicalai.qd.je 中国大陆可访问入口

DATE=2026-09-28T10:30:00+08:00  
MODEL=GPT-5.6 Sol High  
STATUS=READY_FOR_ESA_SETUP

## 目标

必须同时满足：

- 用户访问地址始终为 `https://medicalai.qd.je`；
- 中国大陆用户不直接访问 `*.vercel.app`；
- Vercel 继续作为现有 Production 源站，暂不迁移业务代码；
- 不使用常驻付费 VPS；
- 尽量使用免费托管层；
- `/today`、`/api/status`、AI API 等动态路径都能工作。

## 为什么 redirect.pizza 不够

redirect.pizza 只能返回 301/302。

链路仍然是：

```text
国内浏览器
  -> medicalai.qd.je
  -> 302
  -> medicalchannelai.vercel.app
```

因此浏览器最终仍直接访问 Vercel，不能解决中国大陆对 `vercel.app` 访问不稳定或不可用的问题。

PR #53 已因此关闭，不进入 main。

## 主方案：Alibaba Cloud ESA 反向代理

使用阿里云 Edge Security Acceleration（ESA）作为用户访问层。

目标链路：

```text
中国大陆浏览器
  -> https://medicalai.qd.je
  -> Alibaba Cloud ESA edge
  -> HTTPS origin fetch
  -> https://medicalchannelai.vercel.app
```

浏览器地址栏保持 `medicalai.qd.je`，Vercel 只作为 ESA 的源站。

### 套餐与区域

第一阶段使用：

- ESA Entrance 免费套餐；
- Acceleration Region: Global (Excluding Chinese Mainland)；
- Connection Method: CNAME。

原因：

- Entrance 当前长期免费；
- Global (Excluding Chinese Mainland) 不要求 ICP；
- 中国大陆用户请求可通过境外 POP（香港、日本、新加坡等）访问，避免浏览器直接连接 Vercel；
- 先做真实天津移动/联通/电信测试，再决定是否需要更高等级大陆网络优化。

不声明“大陆节点加速”。如果以后需要真正的中国大陆 POP，需要满足对应 ICP/套餐条件。

## ESA 关键配置

### 用户域名

`medicalai.qd.je`

### Origin

`medicalchannelai.vercel.app`

### Origin protocol

HTTPS / 443

### Origin Host

必须设置：

`medicalchannelai.vercel.app`

不能默认跟随客户端 Host。

原因：客户端 Host 是 `medicalai.qd.je`，而 Vercel 当前没有把该 qd.je 域名配置为 Vercel Custom Domain。若 ESA 回源时仍带 `Host: medicalai.qd.je`，Vercel 可能返回 404/路由错误。

### Origin SNI

设置：

`medicalchannelai.vercel.app`

### Cache

第一阶段保守配置：

- HTML: no forced cache；
- `/api/*`: bypass cache；
- 静态带 hash 资源可后续延长缓存；
- 不缓存 AI POST/API 响应。

## DNS 切换

当前临时入口：

`medicalai.qd.je -> 89.106.200.1 (redirect.pizza)`

不要先删除。

等 ESA 创建站点并生成专用 CNAME 后：

1. DigitalPlat 中删除临时 A `@ -> 89.106.200.1`；
2. 按 ESA 控制台给出的精确接入记录配置；
3. 不猜测 CNAME 值；
4. 等 DNS 生效；
5. 验证 `medicalai.qd.je` 地址栏不跳转；
6. 验证 `/today`；
7. 验证 `/api/status`；
8. 验证 AI 分析请求；
9. 天津手机流量实测。

## 验收标准

必须全部通过：

1. `https://medicalai.qd.je/` 地址栏保持 qd.je；
2. `https://medicalai.qd.je/today` 返回站点；
3. `https://medicalai.qd.je/api/status` 返回 `ready=true`；
4. 无 30x 跳到 `*.vercel.app`；
5. 前端静态资源全部加载；
6. AI 请求可用；
7. 天津至少一个真实移动网络通过；
8. 最好再补联通/电信至少一个；
9. qd.je DNS 不再指向 redirect.pizza；
10. 不保留仅用于本入口的 GCP VPS。

## 回滚

ESA 未验收前保留 redirect.pizza 临时入口。

若 ESA 配置失败，可将 DNS 恢复到：

`A @ 89.106.200.1`

这只能恢复海外/可访问 Vercel 环境下的跳转，不视为中国大陆问题已解决。
