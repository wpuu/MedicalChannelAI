# MedicalChannelAI 方案可行性 × 竞品 × 盈利路径 独立评审（2026-09-29）

> 性质：外部独立评审（Arena Agent），基于 `main@6d49baa` 全量代码、`docs/` 全部文档、线上生产快照（v0.5.0，417 条商机）、7 个开放 PR（含 #71 差异化提案）以及 2026-09-29 联网竞品调研。
> 目的：回答四个问题——**现有方案可不可行？哪里必须改？竞品怎么赚钱、哪些要搬、哪些没解决？怎样变成一个能长期盈利的项目？**
> 立场：不为已投入的 398 次提交辩护，只看证据。

## 0. 一页结论

| 问题 | 结论 |
|---|---|
| 现有方案（"天津医疗渠道商机 + AI 行动建议"）能否长期盈利？ | **按现在的形态不能。** 它本质上是一个"更严谨的标讯订阅"，而标讯订阅在中国已经商品化到 **¥98～¥799/年**，头部竞品信息源多 3～4 个数量级、且全部在微信小程序里。一个人的团队在"信息量 × 更新速度 × 分发"三个维度上无法正面竞争。 |
| 项目的工程资产有没有价值？ | **有，而且是竞品最薄弱的部分：** 证据优先（每个事实有出处）、多时间窗口引擎（文件获取期 ≠ 投标截止 ≠ 质疑期）、更正/终止 fail-closed、公共/私有分层、AI 只做表达层。这些是做"决策级"产品的地基，但目前被用来做"信息级"产品，杀鸡用牛刀。 |
| 需不需要优化？ | **需要，而且是方向级而非功能级。** 应从"告诉你有个项目"转向"告诉你这个项目**能不能投、卡在哪条参数、还剩几天能处理、对手的中标型号站不站得住**"。PR #71 的"参数证据助手"方向是对的，但执行计划要收窄、要先卖服务再做产品、要补数据底座。 |
| 当前最大风险 | 不是技术，是**顺序**：30 天内 398 次提交、30 个分支、约 30 份治理文档，对应的真实用户对话只有 1 个（老杨），付费为 0。产品首页"今日重点" Top5 全是黑龙江项目，而 Pilot 用户在天津——说明没有人以目标用户身份每天用它。 |
| 一句话建议 | **停止扩功能和写治理文档 8 周；用现有引擎在天津做 5 份"参数体检 / 中标核验"样品，卖出前 3 单；同时把天津数据从 12 条补到能用；验证通过再产品化。** |

## 1. 项目现状：代码与数据层面的真实体检

### 1.1 已验证的强项（读代码 + 跑数据得出）

| 能力 | 证据 | 竞品是否具备 |
|---|---|---|
| 证据优先 / fail-closed | `validation.py`、581 项契约测试、`quality_flags`、`published_at_precision` 等精度字段，日期只有官方写明才存 | 竞品是聚合器，字段解析错误常见，无出处定位 |
| 多时间窗口引擎 | `LATE_WINDOW`（报名/获取文件期已过但投标未截止）、`PRE_MARKET_SIGNAL`（采购意向不当作开标）、`RELATIVE_REGISTRATION_WINDOW_7_DAYS` | 竞品普遍只显示一个"截止日期"，正是 9-25 决策里天津 SPECT/CT 案例暴露的错误 |
| 更正/终止对账 | `ccgp_events.py`、`notice_events`、终止覆盖原机会 | 竞品多为"再挂一条公告"，不回写原机会状态 |
| 公共层/私有层分离 + 公共 AI 缓存 | `opportunity_id + fact_hash + window_state + prompt_version` | 成本结构优于"每次点击调一次模型" |
| 零输入即有价值 | 免登录可看核实机会与官方原文 | 竞品普遍注册墙 + 电话营销 |
| 已上线 | v0.5.0，`source_mode=DATABASE`，`FRESH`，AI configured，EdgeOne 国内入口 | — |

### 1.2 已验证的短板（这是决定商业结果的部分）

**(1) 数据覆盖是"商品化"的那部分，且薄。** 生产快照 417 条：413 条来自 CCGP `公开招标公告`，4 条采购意向来自 1 家医院官网。没有 **中标/成交结果**、没有 **竞争性谈判/询价/单一来源**、`tianjin_notice_events.json` 为空（**更正/终止事件实际为 0**）。查询计划 `lookback_days=3`、天津 `max_candidates=12`、其他市场每市 10 条、关键词只有 5 个泛词。

**(2) Pilot 区域最薄。** 市场分布：黑龙江 124 / 北京 98 / 河北 92 / 吉林 48 / 辽宁 43 / **天津 12**。"今日重点" Top5 全是黑龙江。老杨打开首页看到的是佳木斯急救中心。

**(3) 61% 的池子是"进不去"的机会。** `LATE_WINDOW` 255 / 417。窗口引擎判断是对的，但产品把它们留在池里，等于用户每天面对一堆已经关门的项目。

**(4) 没有中标数据 = 没有价格、品牌、型号、经销商情报。** 这恰恰是 MDBIDS / 知了收费的核心，也是做"参数证据库"的原料。`ccgp_discovery.py` 里 bidType 映射早已包含中标/成交/更正/终止，只是查询计划没启用。

**(5) 分发与地理错位。** 目标用户生活在微信里（所有竞品都是小程序优先）；本项目是 Vercel（美国）+ Neon（俄亥俄）的 Web 应用，美国侧 `/api/status` TTFB 约 2 s，国内靠 EdgeOne 反代；天津政府站点屏蔽海外 IP，采集执行面又在退役 GCP runner。一个中国 B2B 产品全部基础设施在海外，是长期结构性摩擦。

**(6) 方向在 30 天内切换了 4 次。** 商机+CRM 覆盖层+AI 投/观望/放弃 → 零信任"阶段+窗口+行动路径" → 渠道资源网络撮合 → 参数证据助手（PR #71）。外加返利审计、Hermes 联通两条支线。每次都写了完整文档，但没有一次拿到付费。

**(7) 过程开销与市场接触失衡。** 7 个开放 PR（#1 自 v0.1 起未合并）、30 个远端分支、`docs/` 约 30 份文件中 20+ 是治理/裁决/审计记录。这是多智能体协作留下的"元工作"，对客户没有价值。

> 判断：**工程质量 A，产品-市场匹配 D，过程效率 C。** 好消息是 A 很难补，D 和 C 可以用 8 周纠正。

### 2.2 竞品怎么赚钱（6 条收入线）

1. **个人/小团队订阅**：¥98～¥7999/年，按省份、按关键词数、按导出权限分层；联系人电话、附件下载是最常见的付费墙。
2. **企业席位与数据 API**：知了服务字节/联想等大客户；众成向厂家卖 MDCloud、定制数据、行业报告，并与协会合资做行业数据平台——**真正的利润在 B 端，不在 ¥98 的 C 端**。
3. **电销升级与线索转化**：注册即触发电话营销，承诺"保证多少单""找到关键联系人"——这是黑猫投诉、知乎里最集中的负面来源。
4. **内容营销 + 报告**：众成每月发布各品类中标品牌市占（MR 2025 年 1641 台、226 亿元），既是免费流量也是付费报告入口。
5. **按次增值服务**：AI 标书 ¥9.9/份、偏离表、代写、保函/垫资引流。
6. **推荐位/精选项目**：剑鱼"推荐项目"由"专业团队筛选"，本质是付费曝光或高阶会员权益。

### 2.3 竞品的优势——应该搬来并做得更好

| 竞品优势 | 我们怎么搬 + 怎么优化 |

| 微信小程序 / 公众号推送，关键词 + 地区订阅 | 先做微信内 H5 + 公众号模板消息（一人可维护），10 个付费团队后再做小程序。**优化点：推送的是"窗口变化事件"**（新机会 / 文件获取期即将结束 / 更正 / 终止 / 中标公示 / 质疑期倒计时），而不是"又抓到一条公告" |

### 2.4 竞品没解决的问题——这是我们的机会

**问题 A：全行业只做"找到项目"，没人做"能不能投 / 卡在哪 / 几天内要干什么"。**
2025 年以来医疗设备采购进入"中标即投诉，投诉即废标"阶段：全国医疗设备集采废标率同比上升 15 个百分点，"质疑维权"案件同比增长 40%，2026 年一季度公开的废标/流标案例已超过 20 起；广西超高端 CT 项目 12 项投诉全部驳回后仍被废标，起因是"最快机架转速"的物理极限值与临床应用值两种应标口径。黑龙江县域医共体设备更新项目经技术面投诉、补位、再废标，历时近 5 个月。废标的两大根源是**参数排他**与**虚假应标**。行业已出现专门研究标书漏洞的"职业质疑"公司。
→ 对渠道商来说，每一次参数之争对应的是几十万到几千万的项目，而处理它的工具只有厂家技术支持 + 人工。**标讯平台不做，AI 标书工具只会生成通用偏离表，没有"品牌 × 型号 × 参数"的证据底座，也不算法定窗口。**

**问题 B：法定时间窗口没有人算。**
质疑期为知道或应知权益受损之日起 7 个工作日，投诉期为答复期满后 15 个工作日（财政部令第 94 号）；需求征集意见有截止日；招标文件获取期与投标截止是两个日期。竞品只给一个"截止日期"。本项目的窗口引擎是现成的，扩展 3 种窗口的成本很低，且**每一条都能引用法条与公告原文**。

**问题 C：证据等级缺失。**
竞品的字段是抓取 + NLP 的结果，无出处、无精度、无"未知"状态；用户要自己回官网核对。本项目的 `evidence locator + precision + fail-closed` 是差异化的底层能力，但目前只用在"公告字段"上，没有用在"参数事实"上。

**问题 D：政策把"招标文件检测"和"投标合规自查"写进了国家文件，但供给端只服务招标方。**
八部委《关于加快招标投标领域人工智能推广应用的实施意见》（发改法规〔2026〕195 号）定义 20 个场景，其中"招标文件检测——自动识别排斥限制竞争问题，鼓励'先体检、再发布'"、"投标合规自查——对照招标文件进行响应性比对"，目标 2026 年底部分省市全覆盖、2027 年底全国推广。筑龙、新点这类交易中心供应商会服务招标人和交易中心；**投标人侧、尤其是中小经销商侧的"体检"是空白。** 同时文件强调"对恶意投诉进行智能筛查"，意味着任何质疑辅助工具都必须是证据驱动而非"找茬"驱动——这正好是本项目的 DNA。

**问题 E：合规红线没有人提示。**
2026 年纠风文件对代理商划出三条红线（免费投放设备绑定耗材、接收虚开发票、异常低价中标），医院正在大幅压缩供应商数量。竞品对此完全沉默。一个"这条机会的合规风险提示"（基于公开规则）是零成本的信任加分项。

**问题 F：信任。**
千里马被投诉"虚假宣传、承诺保证多少单、注册后骚扰电话不断"（黑猫投诉，涉诉 6500 元）；乙方宝被指"手机端和 PC 端双重收费、推送滞后"；剑鱼被指"大会员价格不菲"。**"不电销、不锁字段、不承诺中标、每个结论可点回原文"** 本身就是一种定位。

## 3. 可行性判断：三条候选路线逐一评估

| 路线 | 现状 | 可行性 | 结论 |
|---|---|---|---|
| **A. 更严谨的区域标讯 + AI 行动建议**（当前上线形态） | 天津 12 条；无中标；无小程序 | 商业上不可行：价格锚 ¥98～¥799，且需要与 20 万信息源竞争 | **降级为免费获客层**，不再作为收费主体；但必须把天津补到"能用" |
| **B. 渠道资源网络效应 / 双盲撮合**（`CHANNEL_RESOURCE_NETWORK_EFFECT_PLAN.md`） | 纯设计 | 需要先有数百活跃用户与确认过的能力节点；冷启动问题；反腐环境下"关系撮合"敏感 | **推迟 12 个月以上**，不投入工程 |
| **C. 医疗设备投标"参数证据助手"**（PR #71） | 提案 | 需求被 2025–2026 废标潮和 2026 国家政策双重验证；与现有引擎高度吻合；一人团队可在 1 城 × 2 品类内做深 | **采纳为主线**，但按第 4 节修正执行方式 |

### 对 PR #71 的修正意见（同意方向，修正执行）

1. **先卖服务，再做产品。** 前 10～20 单以"AI 抽取 + 人工复核 + 出具带出处的 PDF"交付，收费按份。产品化只做已经卖出去的那部分。
2. **买家不止经销商。** 三类买家的痛点与预算不同：
   - 经销商老板/商务经理（老杨）：项目级"能不能投、卡在哪、对手站不站得住"，按份付费；
   - **厂家区域经理/投标专员**：预算更高，需要"我方型号在这份参数里的负偏离清单 + 竞品中标型号核验"，是质疑材料的直接使用者；
   - 招标代理机构 / 医院设备科：政策要求"先体检、再发布"，废标意味着设备更新资金被收回，痛感真实；但采购决策链长，作为第二阶段 B 端渠道。
3. **参数证据库必须从"中标公告型号"反推，而不是从注册证正推。** 注册证只有结构组成；彩页与官网规格才有参数；中标公告的品牌型号是免费、合法、结构化的锚点。先做超声 + 内镜（线上数据里数量最多、品牌多、参数多、质疑频繁）。
4. **法律措辞是产品的一部分，不是免责声明。** 只输出"经公开资料比对，该参数在已核对的 N 个品牌中仅见于 X（附证据 1、2）"与"无法证实"，永远不输出"内定""控标""虚假"。这既是合规，也是与"职业质疑公司"划清界限的定位。
5. **数据入口要如实标注覆盖率。** 部分天津项目招标文件需现场领取，这部分标"未获取招标文件，仅基于公告参数"，不猜。

### 4.3 护城河的诚实版本

| 候选 | 是否成立 | 说明 |
|---|---|---|
| 信息量 / 速度 | 否 | 永远输给聚合器 |
| AI 摘要 / 判断 | 否 | 所有人都在用同样的模型 |
| 多窗口 + 更正/终止 fail-closed 的准确度 | 弱→中 | 形成"从不把关门说成开门"的口碑，是免费层的信任来源 |
| **品牌 × 型号 × 参数证据库（带出处）** | 中，复利增长 | 每出一份报告增加一批带证据的参数事实；窄品类做深后短期难复制 |
| **废标 / 质疑 / 投诉处理决定库** | 中 | 从公开的投诉处理决定书积累"哪些参数被判倾向性、哪些型号被判不满足"，是判断质疑能否成立的独有依据，也是最好的内容营销素材 |

### 4.4 单位经济与盈亏平衡

- 基础设施：Vercel + Neon 免费/低档 + 一台国内 VPS（约 ¥50～100/月，用于采集与未来迁移）≈ **¥2000/年以内**。
- 单份报告模型成本 ¥1～5，人工复核 0.5～2 小时（前期）。
- 一人公司盈亏平衡（含机会成本）取 **¥25 万/年**：例如 12 个团队 × ¥12000 + 70 份报告 × ¥1500 ≈ ¥25 万。**一个城市、两个品类内可达成**——前提是第 5 节的验证门槛通过。
- 2026 年设备更新资金 2000 亿元已下达 92%，天津县域医共体单个 CT/DSA 项目即 4420 万元；2026–2027 是窗口期，之后"唯效能论"改革（浙江试点）会让参数战从"数值比对"升级为"证据比对"，对证据型产品反而更有利。

## 5. 90 天执行计划（带停止条件）

### 第 1～2 周：止血 + 样品（不开发新功能，只修数据）

1. **天津数据补齐**：查询计划加入 `中标/成交/更正/终止/竞争性谈判/询价/单一来源`，`lookback_days` 3→30，天津候选上限 12→200；补天津市政府采购网 / 公共资源交易中心 / Top-20 医院官网；采集从国内 IP 执行（现有 GCP runner 退役后用国内 VPS cron PUT 到 `/api/public-snapshot`，架构不变）。
2. **首页按用户地区排序**，`LATE_WINDOW` 默认折叠。让老杨打开看到天津。
3. **5 份人工样品**：回溯天津近 3 个月超声 + 内镜的招标/中标公告，做 3 份参数体检 + 2 份中标核验（AI 抽取 + 人工复核 + 出处）。
4. **3 次真实用户对话**：老杨 + 他引荐的 2 位（至少 1 位厂家区域经理）。只观察强信号：是否转发、是否要"下一个项目也做一份"、是否据此提交意见/质疑。

**门槛 G1**：5 份样品中 ≥2 份找到有公开证据支持的问题；≥1 人主动要下一份。不达标 → 参数方向停止，只保留免费层。

### 第 3～6 周：卖出前 3 单 + 窗口引擎扩展

5. 质疑期 / 投诉期 / 需求征集意见截止 三种窗口进入引擎，卡片显示法条依据。
6. 微信内 H5 + 公众号推送（窗口变化事件）；每周一篇"天津医疗设备招采周报"（更正、终止、中标品牌、废标/投诉决定）作为零成本获客。
7. 收费试单：报告按份收费，目标 ≥3 单、≥2 家互不关联企业、≥1 笔实际付款（对齐 Joint Business Gate A）。
8. 每份报告的参数事实沉淀进 `brand × model × parameter` 表（含证据 URL + 定位 + 证据等级）。

**门槛 G2**：≥1 笔来自非关系户的付款。不达标 → 停止付费层开发。

### 第 7～12 周：产品化已卖出的部分

9. 自助"参数体检"MVP：上传招标文件 PDF → ★ 参数抽取 → 对照证据库分级匹配 → 输出带出处报告 + 质疑倒计时。人工复核仍在环。
10. 团队席位 + 分派 + 微信提醒。
11. 废标/质疑/投诉处理决定库 v0（天津 + 全国 CCGP 医疗设备类）。

**门槛 G3**：≥3 个付费团队或 ≥10 份付费报告，复购率 ≥30%。达标 → 扩京津冀 + 第三个品类；不达标 → 冻结为免费工具，转 WATCHLIST。
